# RSS Music Player

## Purpose

A web application that is designed to enable artists to host and distribute their own
music by allowing users to provide an artist's RSS feed in order to access a list of
their tracks. Users can then play through these tracks using standard playback controls
and can opt to pay the artist using Bitcoin using a value-for-value philosophy.

## Running

The easiest way to run the application locally for development purposes is to use Docker
Compose. This can be done in the root directory of the repository by running:

```
docker compose up
```
